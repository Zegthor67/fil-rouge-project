# StreamFlix

Projet fil rouge : plateforme de streaming avec Bootstrap 5 et SASS.

## Installation

```bash
npm install
```

## SASS

```bash
npm run watch   # compile à chaque sauvegarde
npm run build   # version minifiée
```

## Branches

- `main` : structure HTML
- `cssNatif` : version avant la migration
- `bootstrap-sass` : migration Bootstrap + SASS
